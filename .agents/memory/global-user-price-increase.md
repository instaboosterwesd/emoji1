---
name: Global user price increase
description: Product pricing rule for applying an admin-wide percentage to User prices.
---

The admin global User price increase is percentage-based and applies to every User price, including imported catalog prices and manually configured fixed User prices. Reseller prices are unaffected; entering 0 disables the increase.

**Why:** Admin needs one control to adjust the complete User catalog without editing each product duration individually.

**How to apply:** Apply the percentage after resolving the base User price, round to two decimals, and preserve separate per-product DM/Only Contact and Reseller pricing behavior.
